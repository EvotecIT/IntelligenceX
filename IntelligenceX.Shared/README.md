# IntelligenceX.Shared

`IntelligenceX.Shared` contains the small, platform-neutral contracts and catalogs shared by the IntelligenceX SDK and its supported hosts.

Most applications should reference the main [`IntelligenceX`](https://www.nuget.org/packages/IntelligenceX) package. Install this package directly only when building an IntelligenceX host that consumes the shared tool-routing contracts without the SDK runtime.

```powershell
dotnet add package IntelligenceX.Shared
```

The package targets .NET Standard 2.0 and is released from the [IntelligenceX repository](https://github.com/EvotecIT/IntelligenceX).
